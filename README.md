# 班級寵物探險隊 · 班級寵物加分系統

孩子完成約定，就能獲得成長值與金幣；累積到一定程度，寵物會孵化、升級，還能解鎖新造型。
不用安裝 App，有瀏覽器就能使用；可選擇把資料存在本機，或同步到自己的 Google 試算表。

---

## 快速開始

### 方式一：直接打開（最快）
在檔案總管中雙擊 `index.html` 即可使用（純靜態頁面，不需安裝任何東西）。

### 方式二：用本機伺服器（建議，手機也能連）
```powershell
npx serve .
```
啟動後會顯示一組網址（例如 `http://192.168.x.x:3000`），同一個 Wi-Fi 下的手機、平板輸入該網址就能使用。

### 方式三：放到網路上
把整個資料夾上傳到 GitHub Pages、Netlify、Cloudflare Pages 等靜態空間即可，全部都是靜態檔案。

## 三個入口

| 頁面 | 檔案 | 用途 |
| --- | --- | --- |
| 首頁 | `index.html` | 選擇進入學生前台或老師後台 |
| 學生前台 | `student.html` | 探險地圖、我的寵物、今日任務、班級夥伴、兌換商店 |
| 老師後台 | `teacher.html` | 加扣點、批次操作、紀錄查核、課堂工具、規則設定 |

### 好用的網址參數
- `student.html?me=7` — 直接以 7 號學生的身分打開（也可用姓名，例如 `?me=陳語晴`）。適合幫每位學生做一張 QR code。
- `student.html#pet`、`teacher.html#ledger` — 直接開到指定頁面；換頁時網址會同步更新，重新整理不會跳回首頁。

## 功能對照

### 學生可以
- 選擇自己的寵物、幫寵物取名字
- 用金幣餵食（莓果／小麵包／蛋糕／星星糖），獲得成長值
- 寵物依累積 XP 升級，階段依序為 🥚 蛋 → 🌱 幼生期 → ✨ 成長期 → 👑 完全體 → 🌟 傳說級
- 用金幣解鎖造型（需達到指定等級），可自由穿脫
- 查看自己的徽章、點數紀錄、小隊進度
- 用課堂點數在兌換商店換獎勵

### 老師可以
- **班級總覽**：今日加點、本週活躍學生、即將升級寵物、共同任務進度；表格可直接 ±1 點
- **批次加點**：一鍵選全班／某小隊／自訂多人，套用規則或自訂點數（填負數即扣點）
- **學生與小組**：新增／編輯／刪除學生、調整分組、批次貼上名單匯入
- **課堂小工具**：隨機抽點（抽過不重複）、課堂計時器（時間到有提示音）
- **寵物與徽章**：全班寵物分布、徽章解鎖統計
- **點數紀錄**：依日期／學生／規則篩選，**任一筆都能撤銷**（點數、XP、金幣一起回沖），可匯出 CSV
- **兌換管理**：處理學生兌換申請，標記已領取或退回（退回會回沖點數與庫存）
- **排行榜**：課堂點數、**本週進步**、寵物等級、小隊總點數
- **規則設定**：自訂加分規則、兌換商店、今日任務、班級資訊與共同任務
- **資料與同步**：連結 Google Sheets、匯出／匯入 JSON 備份、新學期重設

## 計分規則（可自行調整）

預設每條規則同時給三種數值：

| 規則 | 課堂點數 | 寵物 XP | 金幣 |
| --- | --- | --- | --- |
| 📚 準時交作業 | +2 | +3 | +2 |
| ❤️ 主動幫忙 | +2 | +3 | +2 |
| 👥 小組合作 | +3 | +4 | +3 |
| 🌱 整理座位 | +1 | +2 | +1 |
| 🔍 上課專注 | +1 | +2 | +1 |
| 🏆 鼓勵同學 | +2 | +3 | +2 |
| 🗺️ 完成共同任務 | +3 | +5 | +3 |
| 💭 溫馨提醒 | −1 | 0 | 0 |

- **課堂點數**：用來兌換商店獎勵，也是排行榜依據
- **寵物 XP**：寵物升級用，升到下一級所需 XP＝`20 + (目前等級 − 1) × 10`
- **金幣**：學生用來餵食與解鎖造型

在「規則設定」頁可以隨時新增規則或調整數值，改完立即生效。

## 連結 Google Sheets（電腦、手機同步）

1. 建立一份新的 Google 試算表
2. 點「**擴充功能 → Apps Script**」，把本專案 `apps-script/Code.gs` 的內容**整份貼上**（取代原本的 `myFunction`）
3. 點「**部署 → 新增部署作業 → 類型選「網頁應用程式」**」
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
4. 部署後複製 `/exec` 結尾的網址
5. 打開老師後台 →「**資料與同步**」→ 貼上網址 → 設定班級代號（例如 `501`）→ 按「**連線並同步**」

連線後：
- 每次加點會自動上傳，其他裝置每 20 秒自動拉取最新資料
- 試算表會自動產生 `學生總覽_班級代號`、`點數紀錄_班級代號` 兩個工作表，可直接在 Google 試算表裡查看
- `_state` 工作表是系統實際讀寫的 JSON（已隱藏），**請勿手動編輯**
- 同一份試算表可用不同「班級代號」放多個班級

> 沒有連線 Google Sheets 時，資料存在該裝置的瀏覽器 localStorage，換裝置或清除瀏覽器資料就會消失，記得定期到「資料與同步」匯出 JSON 備份。

## 換成你自己的寵物圖片

目前寵物用 emoji 佔位。要換成生成的圖片：

1. 把圖片放進 `assets/img/pets/`（例如 `cat.png`）
2. 打開 `assets/js/core/model.js`，找到 `PETS` 陣列，把對應的 `img` 欄位填上路徑：

```js
{ id: 'cat', name: '奶茶貓', emoji: '🐱', img: 'assets/img/pets/cat.png', trait: '陪伴系', desc: '…' },
```

填了 `img` 之後，介面會自動改用 `<img>` 顯示，不需要改其他程式碼。
建議尺寸：正方形去背 PNG，512×512 以上。

探險地圖背景也可以換：在 `student.html` 產生的 `.hero` 區塊套用
`style="--hero-img:url('assets/img/map.png')"`，或直接在 `assets/css/student.css` 的 `.hero` 設定 `--hero-img`。

## 常見問題

**Q：一開始的 40 位學生是什麼？**
A：內建示範資料。要換成自己的班級，到「學生與小組 → 批次匯入名單」貼上名單並勾選「取代現有名單」，或在「資料與同步 → 完全重設」後重新建立。

**Q：學生會不會亂改自己的點數？**
A：學生前台只能用自己已有的金幣餵食／解鎖造型，以及用點數兌換（會產生申請單給老師審核），無法自行加點。所有加點只能由老師後台操作，且每一筆都有紀錄。

**Q：加錯點了怎麼辦？**
A：到「點數紀錄」找到該筆，按「撤銷」，點數、XP、金幣會一起回沖，紀錄會保留並標記為已撤銷。

**Q：可以多位老師一起用嗎？**
A：可以。連結同一個 Apps Script 網址與班級代號即可；系統會以最後更新時間為準同步，建議避免兩人同時大量操作。
