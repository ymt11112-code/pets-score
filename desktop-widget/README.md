# 桌面加點工具

開啟 `dist/班級加點小工具 1.18.0.exe`。請先從舊版工具按「×」結束，再開新版；原本的班級連線設定會沿用。

- 網頁「快速加點」內按「開啟桌面小工具」可啟動本程式。第一次使用先執行本 EXE 一次，完成 Windows 開啟方式註冊；瀏覽器詢問時允許開啟。原有程式已執行時會喚回同一視窗，收合或隱藏時會展開。
- 可攜版註冊的是此 EXE 的固定位置；移動檔案後重新執行一次即可更新。桌面工具沿用自己的班級連線設定，網頁按鈕不會傳送網址、密碼或變更班級。
- 新增出席、抽籤、計時器、今日任務四個小按鈕，會開啟可調整大小的獨立工具視窗。出席與任務由主工具統一存檔及雲端同步。
- 出席可循環切換「出席 → 病假 → 事假 → 喪假 → 遲到 → 早退 → 出席」，也可用每位學生的選單直接指定，或套用全班。病假、事假、喪假與早退會從已選名單及當日抽籤排除，遲到仍可抽取；原始名單與舊版請假紀錄保留。抽到學生後可直接帶回主工具加點。
- 今日任務可設定完成學生名單，沿用網頁任務的 XP 獎勵與已領取紀錄，重複儲存不會重複發獎。
- 關閉工具視窗只會隱藏；計時器繼續倒數，時間到會顯示提醒。結束整個程式才會停止。
- 支援規則庫中新畫的 12 個原創黏土圖示。若其他裝置選用黏土圖示，這台桌面工具也需更新到 1.4.0 以上。
- 頂部控制列依序提供寬度、點數紀錄、隱藏到系統匣、收合與結束。按住整條「班級加點・拖曳移動」標題區或同步狀態列即可移動，不用對準小把手。
- 點「▴」收合成 52 × 52 px 的小腳掌標籤；點腳掌展開，按住腳掌可拖曳。收合時關閉選人視窗、保留已選學生與面板狀態，雲端同步及加分通知繼續運作。
- 五個規則分類名稱已放大，僅影響主工具的分類按鈕。
- 點數紀錄區會隨工具寬度一起縮放，直排貼邊與橫排都適用；較長的姓名與事由會在窄版省略，拉寬後可顯示更多文字。
- 點「↔」顯示寬度滑桿，或左右拖曳面板下角的「↔」把手。寬度可調整為 140–900 px（受螢幕寬度限制），橫排與直排各自記住設定。
- 拖到右側／左側會切換直排；拖到底部／上方會切換橫排。
- 規則與網頁「規則設定」一致，顯示所選分類的全部項目及順序，網頁常用按鈕另於「規則設定 → 網頁批次加點快捷列」挑選，不會限制桌面工具的規則。「加分／扣分」可分開切換，並顯示筆數。
- 網頁更新後，要等桌面工具完成同一班級的雲端同步，才會反映最新規則。

開發啟動：在本資料夾執行 `npm.cmd ci`，再執行 `npm.cmd start`。
打包：`npm.cmd run build:win`。若 Google Drive 掛載磁碟出現 npm 解壓錯誤，請將來源複製到本機暫存資料夾後建置，再把 EXE 複製回來。


1.5.0：七種抽籤動畫與投影、連抽1–5位、任務配對、權重、不重複／重置與整輪排序分組。抽中學生可一次帶回加點。頭像取當前寵物造型、路線與裝備。黏土圖片擴充至60個。

1.5.1：抽籤動畫與結果固定左右同屏，設定移至下方預設收合。抽出結果不自動捲頁，右欄可顯示多人結果；整輪長名單只在結果欄內捲動。

1.6.0：大屏頭像、姓名與座號放大；拉霸欄位修正對比；扭蛋攪拌／掉球／開球；炸彈燃燒引線；六種轉盤色系及可試聽的音效、揭曉聲、緊張程度與音量。設定在抽籤區下方收合卡片。

1.7.0：頭像不壓字；GO／炸彈／問號直接抽籤；寵物浮水印刮刮樂；抽中後自動倒數或正向計時。抽籤與計時器頁共用同一個本機時鐘，隱藏視窗仍繼續，時間到沿用提醒。

1.8.0：新增魔鬼籤與處罰清單；首次連線／換班／重啟先建立通知基準，不重播舊紀錄，過期通知不補播。更新請由主工具最上方×完全結束舊程式，再開新版，以免單一執行個體機制喚回舊版。紀錄不刪除。

1.9.0：選人新增取消選取與完成；加扣分成功後自動取消選取。多人通知摘要與換行，提醒視窗加寬加高。抽籤提供 12 種過程音效、10 種揭曉音效。

1.10.0：與網頁共用獨立規則編號欄位，舊名稱前綴自動拆分；加扣分按鈕只顯示名稱，順序沿用網頁管理的排序。

1.11.0：新增「電子書與手機連線」設定，預留康軒數學、南一國語、翰林社會等六個本機捷徑。可從系統匣選單或網頁系統設定中的 classpet://ebooks 開啟；選取 EXE、LNK 或 PDF 後啟用。與網頁同班級時，手機教材指令可啟動已授權項目。路徑只存在本機，指令持久去重，超時指令不執行。需使用本次新版 Code.gs，Index.html 不需變更。

1.12.0：手機控制通道新增桌面計時器及全部課堂工具。手機可開啟桌面出席、抽籤、今日任務及加點主工具；計時器支援開啟、開始、暫停、繼續、重設與正向計時，狀態回傳手機。請啟用手機控制並使用最新版 Code.gs；未連線時不切回網頁工具。

1.13.0：上方快速加點保留網頁加點；PC 浮動星星使用穩定的本機啟動器，依指定資料夾的數字版本號開啟最新 EXE。系統設定中的「設定／選擇桌面工具資料夾」會開啟 Windows 本機設定視窗。第一次請先關閉舊版並執行 1.13.0 一次；啟動器與資料夾設定存在使用者資料夾，不會上傳。編譯啟動器可執行 launcher/build.ps1。手機和平板的浮動星星則開啟遙控器首頁。

1.14.0：抽籤與計時器拆成各自的獨立視窗，可同時開啟、拖曳邊框調整尺寸、最大化或全螢幕（F11）。重新開啟不強制縮回原尺寸。計時數字隨視窗放大；抽籤結果與動畫左右顯示，長名單可在結果欄內捲動。抽籤後自動計時與手機計時控制，都使用同一個獨立計時器；關閉視窗只隱藏，計時繼續。此次僅需更新桌面 EXE，Code.gs 與 Index.html 不需變更。

1.15.0：手機的出席、今日任務、抽籤先在手機操作，可另按「在電腦顯示／電腦放大／還原／全螢幕／隱藏」。計時器預覽與計時不會自動彈出電腦視窗；手機計時畫面可放大。抽籤右側新增全員名單、搜尋、整頁放大與參加狀態。全螢幕只顯示動畫與名單／結果，隱藏標題、導覽、設定與歷史，右下角退出或 Esc 返回。需更新 Code.gs 並重新部署，Index.html 不需變更。

1.16.0：手機遙控首頁新增「開啟最新版桌面小工具」，從本機已設定資料夾按數字版本選擇新版，執行中為舊版會交接新版。桌面「手機控制與電子書」新增登入 Windows 後背景待命，透過固定本機啟動器啟動資料夾中的最新版而不顯示面板。啟用手機控制時，面板 × 僅隱藏；系統匣「結束（停止手機接收）」才完全停止。電腦須開機、連網，且背景接收開啟。沿用 1.15.0 的 Code.gs，不需再次改動雲端程式。

1.17.0：獨立計時器將 1、3、5、15 分鐘移到計時數字上方，使用大型常用時間按鈕並標示目前選取。窄視窗自動分兩欄。點選設定倒數時間，再按開始；保留暫停、重設及自訂分鐘。此項只需更新桌面 EXE，網站與 Code.gs 不需變更。

1.18.0：計時器新增「考試看板」，可設定評量標題、日期、每科項目／開始結束時間或分鐘數及提醒文字。按時段自動顯示目前科目、考試／休息狀態、倒數與進度；檢查時段重疊。出缺席讀取當天班級設定。支援全螢幕與收合設定，保留一般計時與 1／3／5／15 分鐘快捷。考試設定存在本裝置，與學生點數分開；網頁與桌面各自保存。Code.gs 不需更新。
