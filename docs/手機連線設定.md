# 手機連接教室電腦

## 第一次使用：更新班級的雲端程式

只需更新 `Code.gs`；Apps Script 裡若有 `Index.html`，請保持原樣。這次新增的是計時器與原生電子書控制通道，原來加點的雲端網址及資料都沿用。只需更新原有 Apps Script 部署一次。

1. 在原本存放班級資料的 Google 試算表，點「擴充功能 → Apps Script」。
2. 複製專案的 `apps-script/Code.gs` 完整內容，取代原來程式並儲存。網站按「連接手機」後，若提示需要更新，也有「複製新版雲端程式」按鈕。
3. 點「部署 → 管理部署作業」，選原本的網頁應用程式，按鉛筆編輯。
4. 版本選「新增版本」，按「部署」。沿用原本的執行身分與存取設定；不要另外建立試算表，也不必換 /exec 網址。
5. 回到網站，重新按「連接手機」。

這些遙控指令存在 Script Properties，與學生點數 state 分開；不會清除名單、規則或紀錄。

## 每次上課

1. 電腦打開老師網頁，確認已連接 Google Sheets 的正確班級。
2. 到「系統設定 → 連接手機」點「連接手機／顯示 QR code」，讓手機用相機掃描 QR code。
3. 手機開啟連結。若有後台鎖，先在手機完成解鎖，再按「連接並開啟快速加點」。
4. 手機會載入同一班級；「計時器」可設定秒數、倒數／正向，開始、暫停、繼續、重設，或在電腦顯示。
5. 加點仍是原本的「選人 → 選分類 → 點規則」，透過同一份 Google Sheets 同步。
6. 下課在電腦到「系統設定 → 連接手機 → 結束連線」，停用 QR code。

電腦網頁需保持開啟並連網。無須同一個 Wi-Fi；指令通常需數秒，依 Google 與網路回應速度而定。請等「電腦確認」再重複操作。若手機切到其他 App、螢幕休眠或網路中斷，回到網頁後會重新讀取狀態。

QR code 限老師自己的手機使用，含本班連線資訊及限時控制碼，不含後台密碼。配對有效 4 小時；重整或關閉電腦網頁後，請重新產生 QR code 配對。手機已配對時，原本手機的本機畫面會切換到電腦所使用的雲端班級。

手機的計時器、抽籤、出席、今日任務與快速加點入口，都會開啟 1.12.0 以上的桌面小工具。手機保留選人及加點操作。電腦瀏覽器可能需先有一次點擊互動，才允許播放時間到音效。

## 教材捷徑（6 個位置）

1. 在電腦到「系統設定 → 連接手機 → 設定教材捷徑」，展開要設定的位置。
2. 填入顯示名稱，類型選「超連結網址」或「電腦中的 PDF 電子書」。
3. 網址填 http／https 連結；PDF 按「選取電腦中的 PDF 電子書」，由老師自己選檔授權。
4. 按一次「允許開啟教材視窗」。瀏覽器若擋住彈出視窗，請允許這個網站再試。
5. 手機點連線狀態卡，開啟「連接手機」後，裡面的六格教材區會更新，點教材卡片即可在電腦已準備好的教材視窗顯示。

檔案內容不會上傳，手機只取得名稱、類型、是否可開啟與 s1～s6 的位置編號。網址與檔案授權只存在電腦瀏覽器。換電腦要重新設定；重開瀏覽器後若 PDF 未取得讀取權限，請重新選取該檔。關閉教材視窗後，要再按一次允許開啟。

PDF 可由瀏覽器開啟；原生電子書可透過新版桌面工具啟動。

## 康軒、南一、翰林等電腦電子書程式

1. 關閉舊桌面工具，執行 1.12.0 以上版本，連接和網頁相同的 Google Sheets 網址及班級代碼。
2. 網頁到「系統設定 → 連接手機 → 開啟桌面手機控制設定」，或在 Windows 系統匣小工具圖示按右鍵，選「電子書與手機連線」。
3. 三個預設名稱是「康軒數學、南一國語、翰林社會」。按「選取程式／捷徑」，選擇平常雙擊的原始 .lnk 捷徑或 .exe 程式；也可選 PDF。按「試開」確認。選捷徑可沿用教材原本的啟動參數與工作目錄。
4. 勾選「啟用手機控制」。
5. 網頁進入「設定教材捷徑」，類型選「桌面電子書程式」，指定已連線的桌面電腦和電子書項目。
6. 手機掃 QR code 配對後，在「連接手機」內點教材卡片，桌面工具就會啟動該項目。電腦網頁與桌面工具都需保持開啟。

程式路徑只保存在電腦使用者資料夾，不傳到手機或 Google Sheets；手機與雲端只處理預設位置編號。支援 EXE、LNK、PDF，不接收遠端傳來的路徑或程式參數。

## 手機工具全部在桌面顯示

請關閉舊版桌面工具，改開 1.12.0，並在手機控制設定勾選「啟用手機控制」。手機與網頁配對後，出席、抽籤、今日任務、計時器會在桌面工具顯示；快速加點會展開桌面加點工具，手機仍可選人與加扣分。桌面工具未連線時，手機會提示，不會改開網頁版工具。若有多台電腦，可在「設定教材捷徑」選擇手機工具的顯示電腦。

此版也需將 Code.gs 更新為完整新版，並更新原部署版本。Index.html 不需要修改。

## 浮動星星與桌面工具資料夾

上方「快速加點」仍是網頁加點。PC 點浮動星星會開啟桌面工具；手機與平板則開啟遙控器首頁。裝置依行動系統與觸控能力判斷，不會只因 PC 視窗縮窄就切成手機模式。

第一次請關閉舊版並執行 1.13.0 一次，註冊本機啟動器。預設使用這個 EXE 所在資料夾。若要改位置，在電腦的「系統設定 → 桌面小工具啟動資料夾」按「設定／選擇桌面工具資料夾」，在原生視窗選擇資料夾；可按「測試開啟最新版」。保留檔名「班級加點小工具 x.y.z.exe」，之後將新版放入同一資料夾即可，啟動器按數字版本比較，會將 1.13 排在 1.9 之後。路徑只存在本機。

這次是本機啟動與入口調整，不需要再更新 Code.gs 或 Index.html。

## 1.15.0：手機預覽及電腦視窗大小

手機點「今日任務、挑人、出席、計時器」會先顯示手機畫面。出席與任務的變更仍透過原班級同步；只有按「在電腦顯示」才顯示對應桌面視窗。可從手機按「電腦放大」、「還原」、「全螢幕」或「隱藏」。隱藏視窗不停止計時。

請先完全結束舊版桌面工具，執行 1.15.0，並啟用手機控制。本次需將最新版 `apps-script/Code.gs` 貼到原 Apps Script 專案，管理部署作業 → 編輯 → 新增版本 → 部署，沿用原本 /exec 網址；`Index.html` 不需更新。僅更新網站無法讓舊版 Code.gs 支援新增的視窗控制指令。

抽籤全螢幕只留下動畫及右側名單／結果；右下角「退出全螢幕」或 Esc 可返回。右側「全員名單」支援搜尋及放大名單，不必從轉盤上的小字辨識學生。
