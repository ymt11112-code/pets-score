# 考試計時看板

網頁或桌面小工具開啟「計時器」，切換到「考試看板」。手機可從計時器遙控面板按「考試看板（此裝置）」預覽與設定本機看板。

1. 展開「考試設定」，填寫標題和日期。
2. 每科填入考試項目與開始、結束時間；也能輸入分鐘數，自動計算結束時間。
3. 可新增多科（最多 12 科），設定提醒文字，再按「儲存並顯示看板」。
4. 按「全螢幕看板」投影，Esc 或右下角退出按鈕可返回。

看板使用本裝置的日期與時鐘自動計時：開始前顯示等待倒數，考試中顯示剩餘時間，兩科之間顯示休息／下一科開始倒數，最後一科結束後顯示結束。請確認裝置時鐘及考試日期正確。考試時段不能重疊，也不能跨午夜。

出缺席依所選日期的班級出席設定計算，病假、事假、喪假、早退不計入實到，遲到仍計入。桌面看板目前讀取當天出席；其他日期若未提供紀錄，會顯示待確認。

一般計時器仍可使用 1、3、5、15 分鐘與自訂時間；手機一般計時指令會切回一般計時顯示。考試設定存在各裝置的瀏覽器資料中，網頁與桌面分開儲存，不會更動點數與共用規則。本次需桌面工具 1.22.0，Code.gs 不需更新。
